Ahora la secuencia debería verse así: **Dispositivo A** `Llamando → Esperando respuesta → Conectando → ☎ Llamada conectada` **Dispositivo B** `Llamada entrante → Aceptar → Conectando → ☎ Llamada conectada` Y en videollamada: **A ↔ B** `📹 cámara + 🎙 micrófono + 🔊 audio` Una cosa importante para la prueba: **los dos dispositivos deben abrir NEXUS mediante HTTPS**, por ejemplo tu GitHub Pages. Si uno entra por `http://192.168.100.7:...`, Chrome puede bloquear cámara/micrófono porque las APIs de medios exigen un contexto seguro, salvo excepciones como `localhost`. Si el audio ya funciona pero la cámara falla, este detalle es especialmente sospechoso.
